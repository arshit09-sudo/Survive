# SURVIVE

SURVIVE is a 2D survival game which is made using HTML, CSS and javascript.
The idea is simple : survive in an arena using your orbiting blades to fight enemies, and try to survive as long as you can 


here is a screenshot of the actual game : [![SURVIVE gameplay](screenshots/gameplay.png)](screenshots/gameplay.png)



## ABOUT THE GAME

I made SURVIVE because I wanted to try making an actual game by myself , It's a work in progress , but the basic game is there 

You start with 3 blades orbiting around you and enemies spawn in the arena. There is also a medkit to recover health. I'm still working on adding more and more features and making the game look better.



## HOW TO PLAY

1. open the given link in any browser and start playing https://arshit09-sudo.github.io/Survive/

2. Alternatively you can clone or download this repository , open the Survive folder and then open index.html in your browser
